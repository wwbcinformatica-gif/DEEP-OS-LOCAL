# DEEP-OS — Discovered Knowledge
_Cross-project discoveries extracted from MEMORY.md to stay under token budget._

### Discovered (DEEP-OS)

- **npm 11.x workspace:* doesn't resolve standalone (2026-07-02)**: Running `npm install` inside an example dir with `workspace:*` deps fails with EUNSUPPORTEDPROTOCOL. Must use `file:../../packages/backend` relative paths when installing outside monorepo root. Full `npm install` from monorepo root works fine with workspaces.
- **llmrtc monorepo structure (2026-07-02)**: `@llmrtc/llmrtc-backend` at `packages/backend/`, `@llmrtc/llmrtc-web-client` at `packages/web-client/`, providers in `packages/providers/` (openai, elevenlabs, google, anthropic, etc.), examples in `examples/`. Workspaces configured in root package.json: `["packages/*", "packages/providers/*", "examples/*", "docs"]`.
- **`sendData()` does NOT exist on LLMRTCWebClient (2026-07-02)**: Voice Task Assistant code called `client.sendData(arrayBuffer)` and `client.sendData(JSON.stringify(...))` — both are dead code. The correct LLMRTC audio pattern: `client.shareAudio(stream)` adds audio track to WebRTC peer → server `pc.ontrack` → `RTCAudioSink` → VAD → STT. For push-to-talk: control `audioTrack.enabled` (true on press, false on release). The `LLMRTCWebClient` API surface: `shareAudio()`, `sendAttachments()`, `shareVideo()`, `peer.send()` for JSON.
- **TaskChecklist collapsible pattern (2026-07-02)**: Added expand/collapse via `useState(false)`. Header always visible (clickable), mini progress bar in collapsed mode. Reduced from 180 lines with full layout to ~160 lines with compact default. User request: "deixe este plano de execução em azul que aparece dentro ou encima do chat menor para que não atrapalhe a visualização".
- **llmrtc build order (2026-07-02)**: Running `tsc -b` from monorepo root fails because provider packages aren't built yet. Fix: build providers individually first (`npx tsc -b packages/providers/anthropic packages/providers/bedrock packages/providers/google packages/providers/openrouter packages/providers/lmstudio`), then backend, then web-client. Or run `tsc -b` repeatedly until project references resolve.
- **AI media commands may bypass MediaPlayDialog**: If the AI uses bash `start` command to open files instead of `media_search`/`media_play` SSE actions, the MediaPlayDialog won't trigger. System prompt should enforce using `media_search` action for all media playback.
- **ChatPanel has two onresult handlers**: Lines ~236 and ~274 in ChatPanel.tsx for SpeechRecognition. Both need auto-send timer logic when `autoSendVoice` is enabled. Only the first handler was updated.
- **VoiceAssistant integration pattern**: Component placed in ChatPanel input bar next to mic/speaker buttons. Uses callback props (`onMicActivate`, `onMicDeactivate`, `onSpeakText`, `setVoiceEnabled`) to control parent state — keeps VoiceAssistant stateless regarding mic/speaker state. Button text "VOZ" with green pulse dot when active.
